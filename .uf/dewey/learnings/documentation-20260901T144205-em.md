When adding a new installation method section between existing methods on a documentation page, always check whether the existing transition text needs updating. Pattern: when inserting content between two existing sections, review the transitional text of both the preceding and following sections for accuracy. Example: inserting an RPM section before "On Linux, install from source:" requires changing it to "Or install from source:" because RPM is also a Linux method.
