# PR and Issue Labeling Requirements (Org-Wide Policy)

Every issue and PR — including AI-generated ones — MUST have labels applied. At minimum, use one of these standard labels:

- `bug` — expected behavior is broken or code throws unexpected errors
- `documentation` — changes strictly related to READMEs, wikis, inline docs
- `enhancement` — new features, optimizations, or improvements

Optional labels to apply when appropriate:

- `ai_assisted` (or `llm_assisted` in unbound-force org) — the issue/PR was drafted, structured, or heavily assisted by an AI/LLM tool
- `stakeholder` — product stakeholders have formally reviewed and confirmed the business need

If no suitable label exists, create a new one. Labels have been standardized across the org — use the existing list in each repo.
