# Issue Template and Description Requirements

Issues created by the development team MUST use the repo's issue templates (revised templates available in each repo). This applies to AI-generated issues too.

## Description Standards

Issue and PR descriptions MUST be:

- Concise and easy to scan
- Use short paragraphs, clear headings, and bullet points over long prose
- Provide enough context for reviewers to understand the change

Issues SHOULD include realistic user/stakeholder impact:

- Who is affected
- How the problem shows up today
- How the proposed change improves outcomes

This speeds prioritization and reduces clarification cycles.

## Label Requirements

At minimum, every issue MUST have one of: `bug`, `documentation`, `enhancement`, or another suitable label from the repo's existing list.
