PR metadata requirements for unbound-force org: (1) The `llm_assisted` label MUST be added to any PR where an LLM was involved. (2) Labels, milestone, and priority from the originating GitHub issue MUST be inherited by the PR. (3) The PR MUST be added to both "Unbound Force Planning" project (unbound-force org, #3) and "Compliance Automation planning" project (complytime org, #14), with status set to "Ready for Review". Use `gh project item-add` + `gh project item-edit` pattern. The `gh` CLI requires the `project` scope — if missing, run `gh auth refresh -h github.com -s project` first.
