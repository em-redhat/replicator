PR creation workflow (/finale) MUST follow these rules:

1. Self-assign: Always use `-a @me` on `gh pr create`
2. Labels: Inherit labels from the originating issue AND always add `llm_assisted` for LLM-involved PRs
3. Milestone: Inherit milestone from the originating issue
4. Projects: Add to BOTH organization projects using `gh project item-add` + `item-edit` pattern
